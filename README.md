# TaskFlow Pro

A task management dashboard built using React, JavaScript, and CSS.

## Live Demo

[Click here to view TaskFlow Pro](https://taskflow-pro-sandy-eta.vercel.app/#home)

## Technologies Used
- React
- JavaScript
- CSS
- Vite

## Features
- Add tasks
- Complete tasks
- Delete tasks
- Search and filter tasks

## Run Locally
```bash
npm install
npm run dev
```
